# Style and Revision Checks

Use this reference when a writing skill needs a concrete prose-editing pass instead of more ideation.

## Core style rules

- Prefer short, direct clauses over stacked abstractions.
- Use active voice when the actor matters; use passive voice only when the process matters more than the actor.
- Keep the main verb close to the subject.
- Repeat the same technical term when continuity matters; do not rotate synonyms for style alone.
- Replace vague emphasis words with evidence or remove them entirely.

## Cut-clutter pass

Delete or rewrite:

- dead-weight openers such as "it is well known", "it should be noted", "as can be seen"
- empty qualifiers such as "important", "interesting", "novel" unless you explain why
- generic adverbs such as "very", "quite", "basically", "generally"
- negative forms that have a cleaner positive alternative
- unnecessary "there is/there are" constructions

Prefer:

- "cause" over "give rise to"
- "affect" over "have an effect on"
- "most" over "a majority of"
- "many" over "a number of"

## Paragraph discipline

Each paragraph should do one job:

1. Open with a topic sentence that states the paragraph's point.
2. Support it with evidence, examples, or method detail.
3. End with the local implication or bridge to the next paragraph.

If a paragraph contains two separate claims, split it.

## Revision passes

Run these passes in order:

1. Structure pass: does every paragraph advance the section's purpose?
2. Claim pass: is every major claim backed by a citation, artifact, or figure/table?
3. Verb pass: are the main actions expressed as verbs rather than buried nouns?
4. Clarity pass: cut clutter, shorten sentences, restore key terms.
5. Consistency pass: numbers, units, terminology, figure labels, and citation numbering all match.

## Numerical consistency

Check every:

- percentage against the denominator
- rounded value against the raw value
- figure caption against the plotted quantity and units
- statement in the text against the corresponding table/figure

If a number appears in multiple places, the same value and units should appear everywhere unless you explain the difference.

## Citation and plagiarism checks

- Cite the original source when making a specific factual or methodological claim.
- Treat copied sentence structure as suspicious even if a citation is present.
- Paraphrase from meaning, not from surface wording.
- Avoid self-plagiarism: do not reuse large blocks of previous prose without explicit reason and adaptation.

## Final submission-minded checks

- Title, abstract, main claim, and conclusion should describe the same contribution.
- Figure legends should be self-contained enough to understand the display without re-reading the full text.
- Limitations and uncertainty should be explicit where evidence is incomplete.
- Claims about importance or generality should be narrower than the available evidence when in doubt.
