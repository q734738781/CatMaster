# Phrasing reference

Use this table when a passage needs language revision. Entries flag possible
filler or rhetorical habits, not prohibited words. Change wording only when it
improves the passage without changing evidence, uncertainty or the author's
voice. There is no required paragraph count or intermediate-draft deliverable.

| Pattern | Examples to reconsider | Editing choice |
|---|---|---|
| Inflated importance | pivotal, groundbreaking, a testament to; 具有重大意义、开创性突破 | Name the demonstrated change and why it matters. Keep a strong claim when evidence supports it. |
| Decorative verbs | delve, foster, leverage, showcasing, underscoring; 深入赋能、全面助力 | Prefer the actual action: measured, compared, increased, used. Technical uses remain valid. |
| Vague attribution | experts argue, industry reports, several studies; 有研究表明、业内普遍认为 | Identify the relevant source and what it establishes. |
| Empty transitions | it is worth noting, importantly, furthermore; 值得注意的是、综上所述 | Connect the findings directly when the transition adds no meaning. |
| Manufactured contrast | not X but Y, not merely, not only ... but ...; 不是……而是……、不仅……更…… | State the substantive finding directly unless the distinction itself matters. |
| Negative tails | no guessing, no wasted motion; 并非万能、仍需谨慎 | State a relevant condition precisely; remove unrelated disclaimers. |
| Generic limitation blocks | despite these challenges, future outlook; 机遇与挑战并存 | Explain the specific unresolved mechanism, comparison or next research question. |
| Excessive hedging | could potentially perhaps suggest; 可能在一定程度上或许 | Retain the uncertainty the evidence warrants without stacking hedges. |
| Stock positive endings | promising future, paves the way; 前景广阔、奠定坚实基础 | Close with the supported consequence or a concrete open question. |
| Slogans and punchlines | at its core, the real question is, X is the Y of Z; 本质上、真正的关键在于 | Develop the reasoning rather than announcing profundity. |
| Fragmented prose | sentence fragments, repeated tiny paragraphs, bold labels for every sentence | Join related reasoning; retain lists where items are genuinely parallel. |
| Decorative variation | changing names for the same catalyst, method or quantity | Keep technical terminology stable and vary syntax only when useful. |
| Fake conversational hooks | Honestly? Here's the thing; 说实话、你猜怎么着 | Match the document's register rather than adding artificial personality. |
| Delivery chatter in the artifact | I hope this helps, want me to continue; 以下是为您整理的 | Keep conversation with the user outside the authored report. |
| Process-led revision prose | now corrected, previously missing; 本次新增、此次已核验 | Present the result directly unless the user requested a change log or the chronology is scientific evidence. |

Do not infer poor writing from an isolated word, dash, passive construction,
three-item list or common technical compound. Terms such as long-term stability,
real-time measurement, data-driven modeling, adsorption and reaction mechanisms
can be precise. Dates and access limits belong when they materially constrain a
claim. Necessary negation, adverse results and explicit uncertainty remain.

Do not invent quotations, personal experience, unusual details, mechanisms or
confidence to make text sound more human. Preserve verbatim titles and quoted
material, scientific notation, source attribution and requested formatting.

## Chinese shorthand and unexplained labels

Chinese headings and table cells can be concise while still saying what they
refer to. Restore the omitted object, action or relationship; adding a glossary
for every invented label does not make the explanation natural. These examples
illustrate editing choices, not fixed replacement rules or scientific conclusions
to reuse without checking the surrounding evidence.

| Wording from working notes | Reader-facing wording when supported by context |
|---|---|
| 调查采用：完整／条件 | “计算收敛情况”：已收敛；部分计算点待复核。If inclusion matters, explain separately that both groups are included in this review. |
| 项目采用：物相探索 | “后续实验建议”：先尝试合成该材料，并确认所得产物的组成和晶体结构。 |
| 显著降级／身份待证 | 暂不优先开展补锂性能实验，因为现有证据尚不能确认已制得目标材料。Retain any reported synthesis failure or misidentification and its actual reason. |
| 用途缺证 | 本次检索未找到该材料用于补锂的明确报道。Use this only for a search result; it does not establish that the use has never been disclosed. |
| 未逐ID闭合 | 尚未确认这些计算结构分别对应哪种已报道的实验结构。Explain this only where it affects the scientific comparison. |

An internal ID cannot introduce a material or stand in for a conclusion. When
different structures of one composition must be distinguished, first name the
material and explain that an `mp-…` value is its Materials Project database entry
number. Retain the exact number beside the relevant structure or in a source
table. Explain newly defined sample codes where they first appear; do not create
a parallel code system just to shorten the prose.

Let the reader's question determine whether classification is useful and which
distinctions matter. A label should answer one clear question; it should not
combine unrelated judgments into an unexplained overall status. Keep its meaning
consistent across text and tables. The examples above illustrate how to restore
meaning, not which columns or categories another report should use. Preserve the
requested scientific depth when replacing shorthand with sentences.
