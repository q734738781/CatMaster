# Literature digest format
```markdown
📅 {date} Literature digest | {research field}
Candidates: {candidate_count} | selected: {selected_count} | deferred: {deferred_count} | excluded: {excluded_count}

## Selected

### {title}
{venue/source}, {year} | {authors}
Status: selected — {task-specific reason}
Access: {metadata | abstract | full text | supplementary/source data}
ID: {doi/arxiv/openalex}

Takeaway: {claim grounded at the stated access depth}
Method/conditions: {what was actually inspected}
Key result: {specific result, or state what remains unavailable}
Limitations: {task-relevant limitation}
Link: {stable link}

## Deferred
- {title} — deferred: {reason and condition that would make it useful}

## Excluded
- {title} — excluded: {duplicate or scope/access reason}
```

Do not rank papers by a calculated value or use venue prestige as evidence.
Daily pushes need no forced wiki linkage; archival relationships belong in the
note store when archival is authorized.
