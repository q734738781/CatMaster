# Literature grounding for materials work

For a reported property, benchmark convention or method question, inspect the
supplied sources and relevant workspace evidence first. Use the visible public
search capability for a focused source check when needed. A missing value is an
evidence gap, not permission to launch DFT or another calculation.

Frame the question around the scientific decision: system, quantity, method,
reference state or disputed convention. Search terms should express that
question rather than include the entire reporting brief. Read primary sources
to the depth needed for the claim; abstracts may support bounded statements but
not unstated numerical settings or mechanisms.

Return the supported answer with source handles and conditions needed to use it.
Preserve disagreement when it changes the downstream choice. If this bounded
check cannot resolve the question, state what evidence remains missing; do not
claim access to another role or a literature workflow absent from the visible
tool surface. Stop when the assigned question is answered or a material source
limit prevents it, without turning method grounding into a broad review.
