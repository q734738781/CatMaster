# CatMaster documentation

The maintained manual is available in [Chinese](user-guide/README.zh.md) and [English](user-guide/README.en.md). It is organized around what each agent can accomplish, how skills and tools support that role, and how work moves between agents and project files.

| Read this | When you need it |
|---|---|
| [Quick start](user-guide/01-quickstart.en.md) | Install CatMaster and verify one safe local session |
| [How CatMaster works](user-guide/02-concepts.en.md) | Understand agents, workers, skills, tools, workspaces, and autonomy |
| [The five agents](user-guide/03-llm-configuration.en.md) | Choose Research, Experiment, Literature Review, Writing, or Peer Review and adapt a reference prompt |
| [Experiment workers](user-guide/05-agents-and-modules.en.md) | Inspect the exact scope of Materials, Dynamics, ML, and ORCA/xTB |
| [Modeling and computation](user-guide/06-computational-workflows.en.md) | Follow connected surface, defect, dynamics, MLFF, or molecular workflows |
| [Literature, writing, and review](user-guide/07-literature-writing-review.en.md) | Build evidence, manuscripts, figures, slides, reviews, or revision packages |
| [Remote tasks](user-guide/08-remote-execution.en.md) | Run prepared stages on configured machines and recover interrupted work |
| [Installation and deployment](user-guide/10-deployment-operations.en.md) | Configure models, accounts, servers, external programs, and operations |
| [Prompt library and troubleshooting](user-guide/11-reference-troubleshooting.en.md) | Copy a starting prompt or diagnose a symptom |

The short files under [`readme/`](readme/README.en.md) are compatibility entrypoints for older links. Maintainers can use the current-state references for [DeepAgents integration](deepagents_interactions.md) and [multimodal files](deepagents_multimodal.md). Notable behavior changes made from now on are recorded in the repository [Changelog](../CHANGELOG.md).
