# 6. 建模与计算能力详解

[上一章](05-agents-and-modules.zh.md) | [目录](README.zh.md) | [下一章](07-literature-writing-review.zh.md)

上一章按 worker 介绍了能力。本章换一个角度，从研究者常见的连续任务出发，说明 CatMaster 可以怎样把零散输入推进为结构、计算 stage、结果和分析。这里给出的不是唯一流程。Agent 会根据体系、已有文件、部署中启用的远程 task 和中间检查结果调整路径。

## 从化学式或数据库记录开始

用户不一定已经有一份可计算的 POSCAR。只给出化学式、材料名称或一组筛选条件时，Experiment 可以先查询 Materials Project，比较候选的组成、晶系、稳定性和数据库标识，再下载一个或多个结构。Agent 会保留来源和原始文件，不会把经过标准化、扩胞或松弛准备的结构冒充数据库原件。

如果同一化学式存在多个相，选择哪个结构本身就是科学决定。你可以给出目标相或空间群，也可以让 Agent 先列出候选、解释差异并停下来确认。确定参考结构后，Materials worker 可以建立体相 relax 和 static stage，记录 k 点密度、赝势、泛函、自旋和收敛设置，为表面、缺陷和性质计算提供共同基准。

```text
我想研究 SrTiO3 表面的氧空位，但目前没有结构文件。
请使用 Experiment 先从可靠数据库查找 SrTiO3 的候选体相，比较相、空间群、
稳定性和来源。不要自动挑一个就继续。把原始候选保存下来，并说明哪一个更适合
作为常温立方相或低温相研究的起点；等我确认后再建立体相计算基准。
```

## 从体相到可比较的 slab 与吸附候选

表面建模是一条连续能力链，而不是一个 `build_slab` 按钮。Agent 首先需要确认体相参考是否适合切面，再根据 Miller 指数、最小厚度、真空和面内尺寸生成全部可能终止面。随后它会检查 slab 法向、上下表面、化学计量、极性、重复层、表面配位和固定层，必要时用结构渲染辅助判断。

当目标继续到吸附时，Agent 会读取你提供或生成的吸附物，确定锚点和合理构象，在去重后的表面位点上放置候选，并保留位点、朝向和初始距离的 provenance。初始结构不会被当作稳定吸附态。候选可先经过几何检查，再由启用的 MLFF backend 做单点或松弛预筛，最后只为值得保留的结构准备一致的 VASP 或 CP2K stage。

完整工作可以停在任何合理边界。第一次合作时，建议停在候选与审计阶段；确认结构后再批准预筛或 DFT。这样既利用 Agent 的自主性，也避免一次 prompt 直接扩张为大量远程作业。

```text
从 structures/pt_bulk_relaxed.vasp 建立 Pt(111) 上 O、OH 和 OOH 的吸附候选，
用于后续 ORR 自由能比较。请让 Materials worker 自主组合 slab、termination、
adsorbate、site screening 和 structure inspection skills。

首先建立满足至少 15 Å 真空和合理覆盖度的表面，解释固定层策略并保留约束。
对每种中间体生成化学上合理且去重的位点与朝向，检查跨周期距离和碰撞，
保存候选表、结构图和生成参数。候选过多时可以提出 MLFF 预筛计划，
但在我确认 slab、覆盖度和候选集之前不要提交任何计算。
```

如果你只想处理一个局部问题，也可以把范围收窄：

```text
读取 structures/stepped_ceo2.vasp，只检查最高表面附近配位数为 1 的 O。
请先给出配位定义、截断依据、原子索引和高度，不要凭渲染图删除原子。
在我确认目标原子后再生成删除版本；全程保留现有 Selective Dynamics，
并比较修改前后的最短距离、配位和化学计量。
```

## 缺陷与掺杂筛选可以推进到什么程度

CatMaster 可以枚举对称不等价位点，为空位、取代和显式间隙位置建立候选，并把每个结构放入一致的计算目录。对于第一轮筛选，Agent 可以比较几何稳定性、相对总能和局部配位，也可以在同一体相参考下准备 VASP stage。

完整缺陷形成能需要更严格的定义，包括化学势边界、电荷态、费米能级、有限尺寸与电荷修正。当前工具可以承担结构生成和标准化计算准备，但 Agent 应把这些额外物理条件显式列出。用户若只说"比较氧空位"，它不应默认为已经解决所有电荷和化学势问题。

```text
为 anatase TiO2 的 3x3x1 超胞建立表面与次表层氧空位候选。
请先枚举对称不等价 O 位点并说明分类依据，再生成中性缺陷结构，
检查局部配位、原子重叠和 Selective Dynamics。准备一致的 VASP relax stage，
但把这一步明确标为第一轮结构筛选。

另写一节说明若要报告正式缺陷形成能，还缺少哪些化学势、电荷态和修正设置。
本轮不要擅自补这些条件，也不要提交计算。
```

## 从端点到反应路径、能垒和自由能

NEB 类任务最容易因为端点和原子映射问题产生看似收敛、实际错误的结果。CatMaster 会先确认初态与终态属于同一体系，元素、原子顺序、固定原子和周期性一致。移动原子映射不合理时，可以在保持冻结部分不变的前提下重新对应终态原子。之后才估计图像数、生成插值路径并检查跳胞、碰撞和非连续重排。

路径准备完成后，可以先用 MLFF NEB 做低成本检查，也可以准备 VASP plain NEB，再进入 CI-NEB 或 dimer 精修。计算结束后，Agent 可以提取相对能量和能垒，检查端点能量基准、最大力和路径形状。真正的过渡态通常还需要频率或 IRC 类证据。

表面自由能或反应自由能还需要把电子能与 ZPE、热焓、熵、温度和标准态放在同一基准下。Materials worker 可以处理气相与吸附态频率校正，并把每项贡献写成可检查的表。它不会把不同方法、不同温度或不同参考态的数字直接相减。

```text
比较 structures/co2_initial.vasp 与 structures/co2_final.vasp 之间的表面反应路径。
先做端点、约束和原子映射审计，生成一条连续且可视化检查的路径。
根据位移与化学变化建议图像数，并说明是否值得先用当前 MLFF backend 预优化。

在我确认路径前不要准备正式 VASP NEB。最终计划应区分路径预筛、plain NEB、
CI-NEB、TS 频率验证和自由能校正，每一步写明能回答什么以及不能证明什么。
```

## 能带、DOS、声子、弹性与热力学不是孤立后处理

电子结构和材料性质依赖前置结构与计算设置。对于能带和 DOS，Agent 会从经过接受的体相或表面结构出发，保留 SCF 基准，记录 k-path 来源、费米能级、展宽、自旋和投影定义。`generate_kpath` 与 `vasp_band_prepare` 可以建立高对称路径和专用输入，但具体解释仍需结合体系。

有限位移声子工作会先生成一致的超胞位移结构，再组织力计算。虚频需要区分数值噪声、声学支、超胞不足和真实不稳定模式。有限应变弹性工作则要求控制应变幅度、松弛策略、对称性和拟合区间。Agent 可以生成应变集合并收集应力或能量结果，不会只凭一个拟合数字判断材料可靠性。

热力学工具可以从 VASP 频率输出计算气相或吸附态校正。Agent 会区分电子能、ZPE、热焓、熵和自由能，并保留温度、压力、标准态和受限自由度等假设。对于表面吸附物，通常只对吸附物相关振动做明确处理，不能无说明地把整个 slab 的频率混入同一公式。

```text
基于 calculations/bulk_relax/CONTCAR 为这个半导体准备 DOS 和 band 工作。
请先检查 relax 是否真正收敛、结构是否仍适合作为体相参考，再确定 SCF、DOS 和 band
之间需要继承的文件与设置。k-path 必须记录来源，不能凭经验手写后不说明。

先生成输入与一份预期分析说明，不提交计算。说明最终图中费米能级、自旋、投影和
带隙应该怎样定义，以及哪些结果需要更高精度或独立方法验证。
```

## 从初始结构到可分析轨迹

动力学任务通常经历准备、运行、健康检查和性质分析。准备阶段需要明确 ensemble、温度、压力、时间步、总时长、thermostat/barostat、速度来源、随机种子、边界条件和输出间隔。Restart 任务还要确认坐标、速度、积分器状态和随机状态是否连续，不能只复制最后一帧后当作无缝续跑。

CatMaster 可以为 CP2K AIMD、LAMMPS 和 MLFF MD 组织这些输入。远程运行后，Dynamics worker 先检查日志、轨迹、温度、能量、体积、异常力、结构破坏和帧数。只有这一步通过，才会根据研究目标选择 MSD、RDF、配位数、驻留时间、团簇连通性或扩散拟合。

```text
从 calculations/aimd_800K_part1/ 继续 CP2K AIMD 到总计 100 ps。
请让 Dynamics worker 先审计现有 restart、最后有效步、速度、温度和随机状态来源，
判断是否能连续续跑。不要覆盖 part1，也不要在证据不足时从最后一帧重新赋速。

建立新的 continuation stage，并写明新旧段怎样拼接、需要保留哪些 restart 文件、
怎样检查时间轴连续。先准备和审计，等待我确认后再提交 cp2k_execute。
```

```text
分析 trajectories/pd_tio2_1073K.traj 中 Pd 团簇的演化。
请先做轨迹健康检查，再根据周期边界计算 Pd-Pd 接触图和连通分量随时间的变化，
同时检查 Pd 与载体的最近接触。阈值需要给出物理或结构依据，并做敏感性说明。
不要只用终态截图判断是否烧结；输出时间序列、代表帧和可复现分析脚本。
```

## 从参考计算到可评估的 MACE 模型

机器学习势工作并不是"把 OUTCAR 丢进训练"。CatMaster 可以从多个 VASP run 中提取结构、能量、力和应力，排除未收敛或标签不完整的结果，统一单位和参考能，再形成 extxyz 数据集。固定的数据划分与 manifest 会让后续训练和比较可复现。

ML worker 可以准备并远程运行 MACE training 或 fine-tuning，保存参数、日志和 checkpoint，再在 held-out test 上评估能量、力和应力误差。评估不只看总体均值，还要关注元素、构型类型和高能区域是否存在系统偏差。主动学习可以从未标注结构池中结合多样性与 committee disagreement 选择下一批参考计算，但它不会自动授权昂贵标注。

```text
使用 calculations/vasp_labels/ 和 ml/candidate_pool/ 设计一轮 MACE 主动学习。
先由 ML worker 审计现有标签、数据重复、元素与局部环境覆盖，以及当前 train/valid/test
是否泄漏。然后评估候选池与训练集的差异，结合多样性和可用的模型分歧提出一批候选。

输出候选结构、选择理由、预期补充的环境和参考 VASP 标注计划。
不要直接提交标注或训练；先让我确认候选规模与成本。
```

## 从 SMILES 到构象、ORCA 性质和反应路径

分子任务可以从 SMILES、XYZ 或已有 ORCA 结果开始。Agent 能生成三维结构和构象集合，先用几何与指纹去重，再通过 CREST 或 xTB 做搜索、预优化和低成本排序。筛选后的构象可以进入 ORCA opt、freq、opt+freq、TDDFT 或 NMR。

对于过渡态，用户可以提供反应坐标做 relaxed scan，也可以提供明确的反应物与产物做 NEB-TS。Agent 会从扫描峰或路径附近选择 TS guess，准备 OptTS，并用频率检查是否有且只有预期虚频；IRC 用于确认 TS 是否连接目标端点。柔性分子的 NMR 还需要各构象的相对自由能和 Boltzmann 加权，不能只计算一个最低能构象。

```text
研究这个柔性分子的 298.15 K NMR。输入为 structures/molecule.sdf，总电荷 0，
自旋多重度 1，溶剂为 chloroform。

让 ORCA/xTB worker 先建立覆盖合理的构象集合，使用 CREST/xTB 清理和去重，
再建议进入 ORCA NMR 的构象与方法。保留每一步的相对能、筛除理由和结构。
最终计划需要说明频率自由能、Boltzmann 权重和化学位移汇总怎样衔接。
本轮先准备候选和计算计划，不提交远程任务。
```

## "已生成""已运行"和"已回答"是三个不同阶段

CatMaster 可以把一项工作推进得很远，但用户需要区分三个状态。生成输入或结构，说明建模阶段完成；远程程序正常退出，说明执行阶段结束；只有在收敛、结构、日志、物理合理性、误差和比较基准都经过检查后，结果才有资格回答研究问题。

Agent 的最终回复应指向对应文件，而不只说"完成了"。你可以要求它在每个阶段说明当前证据能支持什么、仍然不能支持什么，以及继续工作前需要哪些决定。涉及真实远程执行时，[下一章之后的远程 Task 章节](08-remote-execution.zh.md)会说明 Agent 如何查询部署能力、提交 stage、保存 receipt 并处理失败。
